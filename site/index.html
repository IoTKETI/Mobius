사물이 보내는 데이터를,
표준 그대로 받아 둡니다.

Mobius는 oneM2M 국제 표준을 구현한 IoT 서버 플랫폼입니다. 기기가 올린 데이터를 트리 구조로 저장하고, 애플리케이션에는 그 트리를 그대로 REST API로 열어 줍니다. 설치부터 구동, 활용까지 이 가이드 하나로 따라갈 수 있습니다.

버전 3.0.1 데이터베이스 MySQL · SQLite 런타임 Node.js 라이선스 BSD 3-Clause

담긴 내용 / What is inside

Mobius란 무엇인가

oneM2M이 정한 IN-CSE가 하는 일, 리소스 트리가 곧 주소가 되는 구조, 기기와 애플리케이션 사이에서 맡는 역할.

내부 구조

요청 하나가 지나가는 길, 모듈이 나뉜 기준, 마스터와 워커의 역할, 데이터베이스 계층이 백엔드를 감추는 방식.

설치와 구동

MySQL과 SQLite 두 갈래 설치, 첫 실행 마법사가 묻는 일곱 가지, 설정을 보고 바꾸는 명령.

실제 활용

AE 등록에서 데이터 저장, 조회, 탐색, 구독 알림, 접근 제어까지 그대로 실행되는 예제.
