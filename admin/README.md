# Mobius 관리 콘솔

Mobius 와 **같은 저장소, 다른 프로세스**로 도는 관리자용 조회 서버.

현재는 **조회 전용**이다. 삭제·`et` 연장은 아직 없다 — 워커 간 캐시 무효화가
먼저 들어가야 한다. 없으면 지운 리소스를 다른 워커가 계속 `200` 으로 돌려준다.

## 무엇을 보여 주는가

**만료된 리소스** — `et`(expirationTime)가 이미 지난 것들. 배포 서버 표본에서
`et` 값의 약 81% 가 이미 과거였다. 만료 스윕은 **주기 실행이 걸려 있지 않아서**
(자동으로 돌리면 지금까지 안 지워진 것이 한꺼번에 사라진다) 이 목록은 저절로
줄어들지 않는다.

목록은 타입별로 다르게 표시한다. 판단에 필요한 구분이기 때문이다.

| 표시 | 뜻 |
|---|---|
| 자동 삭제 안 됨 | AE·CNT·CSEBase. 삭제 경로가 의도적으로 제외한다 — 계속 쌓이는 쪽이 이들이다 |
| 만료 시 자동 삭제 | ACP. 사라지면 참조하던 리소스의 유효 권한이 조용히 바뀐다 |
| 수동 정리 대상 | 그 외 |

## 실행

`conf.json`(Mobius 와 같은 파일)에 아래를 넣는다.

```json
{
  "adminPassword": "...",
  "adminPort": 7580,
  "adminHost": "127.0.0.1"
}
```

`adminPassword` 가 없으면 뜨지 않는다. "일단 열어 두고 나중에 잠근다" 가 되면
나중은 오지 않는다.

`adminHost` 는 기본이 루프백이다. 조회 전용이라도 운영 리소스 트리를 그대로
보여 주므로 기본값이 외부 공개면 안 된다.

```
# 프런트엔드 빌드 (한 번)
cd admin/web && npm install && npm run build

# 콘솔 실행 (백엔드는 Mobius 와 같은 규칙 — argv 가 conf 를 이긴다)
node admin/server.js sqlite
node admin/server.js mysql
```

개발 중에는 Vite dev server 를 쓴다. `/api` 는 콘솔 서버(7580)로 프록시된다.

```
cd admin/web && npm run dev     # http://localhost:5173
```

## 설계 메모

**읽기는 DB 를 직접 본다.** oneM2M discovery 로는 "만료된 리소스를 `et` 순으로"
같은 질의를 표현할 수 없다. `mobius/db` 파사드를 그대로 쓰므로 MySQL/SQLite 를
콘솔이 따로 알 필요가 없다.

**전체 건수를 세지 않는다.** 배포의 `lookup` 은 5,740만 행이고 MySQL 에는 `et`
인덱스가 없다. 끝까지 세면 풀스캔이라, 상한에서 끊고 "47+" 처럼 보여 준다.

**페이징은 `(et, ri)` 키셋이다.** 오프셋 페이징은 뒤로 갈수록 느려진다. `et`
하나만으로는 같은 `et` 를 가진 행이 잘려 유실되므로 `ri` 를 함께 쓴다.

**쓰기는 아직 없고, 생기면 oneM2M HTTP API 를 경유한다.** DB 에 직접 쓰면
워커별 캐시·구독 알림·부모 카운터가 전부 어긋난다.
